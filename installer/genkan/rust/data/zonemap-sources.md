# Time zone map data

`world.bin` and `zones.tsv` are generated by `examples/zonemap-data.rs`:

```text
cargo run --release --example zonemap-data -- SOURCE_DIR rust/data
```

SOURCE_DIR must contain these files, verified by SHA-256:

Natural Earth data is in the public domain. The time zone bands are
standard-time offsets as of 2012, so a few regions are out of date; the
installer uses them only to choose between a country's zones and to shade
the selected region, while the zones themselves come from the live
system's tzdata. CLDR data is © Unicode, Inc., under the Unicode License V3 in
`LICENSE-CLDR.txt`.
