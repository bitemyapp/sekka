# Aizome per crate (experiment)

Not used by any package, system or check. This builds Aizome's compositor,
the `aizome` binary, its core dylib and the hot-swapped logic library, with
one Nix derivation per crate, the granularity Bazel's `rules_rust` uses, to
measure what that costs and saves against `../package.nix`, which compiles the
whole workspace in one derivation and one Cargo run.

```sh
nix build .#aizome-per-crate.compositor .#aizome-per-crate.logic
nix build .#aizome-per-crate.monolithic   # the same two packages in one derivation
nix eval .#aizome-per-crate.workspace.drvPath   # every member, per crate (evaluated, not built)
```

`Cargo.nix` is generated by crate2nix 0.15.0 from the workspace's
`Cargo.lock`, checked in rather than generated during evaluation (crate2nix's
import-from-derivation mode would make every evaluation wait on a build of
the generator's output):

```sh
cd desktop/aizome
nix shell nixpkgs#crate2nix nixpkgs#cargo nixpkgs#rustc nixpkgs#nix-prefetch-git \
  -c crate2nix generate -f Cargo.toml -o nix/per-crate/Cargo.nix
```

nixpkgs' `buildRustCrate` then runs rustc once per crate. `default.nix` sets
the release profile (four codegen units, line tables only), and
`overrides.nix` adds what Cargo's single build finds by itself; Bazel's
`crate_universe` needs the same facts as crate annotations.

The packaging steps of `../package.nix` (the core's std beside it, the
compiler out of the run path, the run path to the libraries opened with
dlopen) aren't repeated here: they belong to one final derivation either
way.

## Results (wx-workstation, 2026-11-03)

Details, method and load for each number are in the pull request that
added this directory. In short, for the compositor and its logic (249
crates; builds with `--max-jobs 8 --cores 16`):

| | per crate | one derivation |
|---|---|---|
| Evaluation (one thread, no eval cache) | 1.6–1.7 s | 1.5–1.8 s |
| Cold build | 163–172 s | 109–110 s |
| Comment in the logic crate (a leaf) | 13 s, 2 rebuilt | 108 s |
| New function in aizome-theme (under the core) | 73 s, 5 rebuilt | 108 s |
| Comment in Sukumo's engine | 89 s, 5 rebuilt | 111 s |

The whole workspace per crate evaluates in 4.5–4.7 s against 1.9 s for
`../package.nix`: 816 crate derivations for 514 distinct crates, because
crate2nix resolves features per workspace member where Cargo unifies them.

`overrides.nix` lists what had to be declared by hand; Koe (whisper.cpp with
OpenBLAS and Vulkan) and aizome-media (FFmpeg and PipeWire bindings) build
with them too (`.#aizome-per-crate.koe`, `.media`).
